# Taskloom

A lightweight C++ task manager library for Linux.

## Requirements

* A C++ compiler supporting C++20 (`g++ 11+` or `clang++ 13+`)
* Linux Environment

### How to setup

```bash
git clone https://github.com/sudoRebel/Taskloom.git && cd Taskloom
```

## Utility tools

* Used AI to clarify the exceptions, naming
* the variables && create the `structure.txt` file.
